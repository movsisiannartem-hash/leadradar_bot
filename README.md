# 🎯 ClientRadar Bot — Автоматический радар IT-заявок и лидогенератор

Интеллектуальная система мониторинга **170+ Telegram-чатов и каналов** в реальном времени. Радар автоматически фильтрует 95% информационного шума (резюме, флуд, спам), определяет реальные заказы на разработку и доставляет их в Telegram с готовым персонализированным AI-откликом в один клик.

---

## ⚡️ Ключевой функционал

* 🛰 **Потоковый мониторинг MTProto:** Чтение сообщений из сотен открытых и закрытых групп в реальном времени с минимальной задержкой (1–3 секунды).
* 🛡 **Интеллектуальная предфильтрация:** Двухуровневый алгоритм за миллисекунды отсекает резюме соискателей («ищу работу», «обо мне», «портфолио»), спам, рекламу каналов и сообщения ботов-модераторов.
* 🧠 **AI-классификация на базе LLM:**
  * Определение реального намерения заказчика (поиск исполнителя).
  * Рубрикация по направлениям разработки.
  * Извлечение бюджета, сроков и ключевых требований ТЗ.
  * Формирование продающего индивидуального отклика под задачу с учетом стека технологий.
* 📲 **Интерфейс Telegram-бота:**
  * Интерактивная карточка лида с прямым переходом в диалог с заказчиком в один клик.
  * Кнопка быстрого копирования сгенерированного питча.
  * Раздел закладок и сохранения избранных проектов.
  * Центр управления категориями уведомлений с интерактивными фильтрами.

## 🏗 Архитектура решения

1. **Userbot (MTProto Client):** Безопасный фоновый слушатель обновлений в режиме *Read-Only*.
2. **Fast Pre-Filter Engine:** Экспресс-анализ по триггерам спроса и стоп-словам для оптимизации затрат на AI.
3. **AI Pipeline:** Классификатор и генератор первого отклика с адаптацией под профиль специалиста.
4. **Alert Bot (Aiogram 3):** Доставка мгновенных уведомлений в личные сообщения с интерактивными кнопками управления.
5. **Storage:** Локальная база данных с дедупликацией кросс-постинга (исключает повтор одинаковых заявок из разных групп).

---

## 🔒 Безопасность и архитектурные решения

* **Read-Only режим:** Скрипт-слушатель работает исключительно на прием входящего потока данных и не выполняет рассылок в чаты от лица аккаунта.
* **Изоляция данных:** Все учетные данные, сессии авторизации и базы данных хранятся в изолированном защищенном контуре.
