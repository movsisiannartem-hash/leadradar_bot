# 🎯 ClientRadar Bot — Telegram Радар Заявок и Лидогенератор

Автоматический мониторинг **170+ Telegram-чатов и каналов** в реальном времени, экспресс-фильтрация резюме и спама, AI-классификация заявок на разработку (боты, сайты, 1C, amoCRM, SEO, UI/UX, ИИ) и мгновенная отправка в Telegram с готовым откликом в один клик.

---

## ⚡️ Возможности

* 🛰 **Userbot MTProto (Telethon):** Читает сообщения из любых открытых и закрытых чатов/каналов в реальном времени без прав администратора.
* 🛡 **Двухуровневая фильтрация (Экономия 90% токенов):**
  1. *Экспресс-фильтр (Regex & Stopwords):* за 1 мс отсекает резюме («ищу работу», «обо мне», «портфолио»), спам, крипту и взаимный пиар.
  2. *Дедупликация:* исключает повторы, когда заказчик спамит один и тот же текст в 10 чатов подряд.
* 🧠 **AI-классификатор (Gemini 2.0 Flash / GPT-4o-mini):**
  * Определяет, является ли сообщение реальной заявкой от клиента.
  * Рубрикует по направлениям: `боты`, `сайты`, `1С`, `amoCRM`, `SEO`, `дизайн`, `ИИ`.
  * Извлекает бюджет, срочность и краткую суть ТЗ.
  * Генерирует **персонализированный продающий отклик** от первого лица с учетом вашего опыта.
* 📲 **Telegram Bot (Aiogram 3.x):**
  * Карточка лида с кнопкой `💬 Написать заказчику` (прямой переход к автору).
  * Кнопка `📋 Готовый отклик` (копирование питча в один клик).
  * Кнопка `☆ В избранное` для сохранения интересных проектов.
  * Интерактивное меню `/categories` с чекбоксами для фильтрации нужных направлений.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните поля в `.env`:
1. **`TG_API_ID` и `TG_API_HASH`**: Получите бесплатно на [my.telegram.org](https://my.telegram.org) в разделе *API development tools*.
2. **`BOT_TOKEN`**: Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и вставьте токен.
3. **`ADMIN_CHAT_ID`**: Ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)) или ID закрытого канала для уведомлений.
4. **`GEMINI_API_KEY`** или **`OPENAI_API_KEY`**: Ключ для работы нейросети.
5. **`USER_PORTFOLIO_SUMMARY`**: Описание вашего стека и опыта — нейросеть будет опираться на него при составлении откликов.

## 🧪 Тестирование без запуска юзербота

Вы можете сразу проверить, как система фильтрует сообщения и формирует карточку с откликом:

```bash
# Тест 1: Валидная заявка на разработку бота
python main.py --test "Здравствуйте! Требуется разработчик Telegram-бота для службы доставки еды. Нужен каталог товаров, корзина и подключение онлайн-оплаты. Бюджет 45 000 руб. Пишите в лс с кейсами."

# Тест 2: Сообщение-резюме от исполнителя (будет автоматически отклонено)
python main.py --test "Привет всем! Я Python разработчик с опытом 3 года. Ищу работу и заказы, мое портфолио в закрепе. Пишите!"
```

Запуск всех модульных тестов:
```bash
python -m unittest tests/test_radar.py
```

## ▶️ Запуск радара в реальном времени

```bash
python main.py
```

При первом запуске Userbot попросит ввести номер телефона и код подтверждения из Telegram для создания локальной сессии (`data/radar_userbot_session.session`). После этого он будет подключаться автоматически.

## 💡 Полезные советы для работы с 170+ чатами

1. **Безопасность аккаунта:**
   * Не используйте свой личный номер. Купите отдельную SIM/eSIM и зарегистрируйте отдельный аккаунт для парсинга.
   * Вступайте в чаты постепенно: не более 15–20 чатов в день, чтобы избежать временных ограничений от Telegram.
   * Аккаунт работает в режиме **Read-Only** (ничего сам в чаты не пишет), поэтому риск бана минимален.
2. **Настройка рубрик в боте:**
   * Откройте вашего бота в Telegram и отправьте `/categories`.
   * Отключите ненужные вам категории (например, если вы не занимаетесь 1C или amoCRM, снимите галочки).
